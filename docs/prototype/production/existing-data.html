字段对照：现有字段能展示什么

目标态原型里的排产、班组、批次、绩效字段，在当前库中不存在。

现有字段 / 表现在能展示缺口与影响
work_order.current_status
config_date / config_complete_time		任务状态、生产开始与完成日期没有“任务计划开始时间”，排产缺少顺排起点
work_order_process_execution.start_time / end_time实际起止、实际用时被状态推导当作实际值；没有独立的计划起止字段，写入未来计划会把工序误判为已完成
work_order_process_execution.step_order工序顺序没有唯一约束；现有 2 个工单第 9 步各重复 1 行，排产按 step 唯一建表会冲突
preparation_process_template.standard_duration / standard_qty字段存在，可展示标准工时与标准数量131 条模板中 0 条有值，无法按标准时长自动顺排
process_qty实际加工数量语义是实际数量；没有工序/批次的计划数量字段
operator_name / operator_id操作人姓名98 条执行记录 operator_id 全部为空，无法关联人员档案，无法按人生成绩效
room_id / equipment_id实际使用的房间与设备现有校验只覆盖设备时间冲突，没有房间冲突、班次冲突、工序顺序校验
无班组 / 班次表—无法做班组视图、班次校验，也无法表达“一个班组同时看多台设备”
无批次表—一道工序只能落一条执行记录，无法拆多个生产批次
production_process_record字段可展示计划级工序记录当前 0 行；与工单级执行记录并存，不能作为绩效的唯一数据源
无绩效 / 系数版本表—绩效工时、个人工作时间、工序/人员系数、版本快照都没有落点
