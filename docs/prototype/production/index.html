主流程

排产结果回写生产任务，实际执行生成工序记录，工序完工后落到个人绩效。

1选择生产任务按任务计划开始时间顺排
2工序拆分批次一次工序可拆多次生产
3指派班组 / 人员批次级登记参与人
4冲突校验资源跨任务比对
5工序完工实际时长与数量定格
6生成个人绩效按人、按批次汇总
拆分口径

工序拆分为多个生产批次后，各批次的计划起止、数量与参与人独立维护，批次数量合计须等于工序计划数量。

绩效口径

同一批次内多人参与时，每人按批次实际时长全额计入；汇总为人时口径，人时合计可大于工序工时。
