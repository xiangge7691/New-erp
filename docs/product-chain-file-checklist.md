## 1. 怎么用

1. 先看“建议”列，判断是否认同。
2. 在“确认结果”列填写：**必传 / 条件必传 / 可空缺**。
3. 确认后，原型里的“缺件”判定会按这个结果调整：必传缺失才计入缺件，可空缺不再提示。
4. 当前原型为了把问题暴露出来，暂时把所有已接入的上传槽位都按“必传”计算，所以缺件数偏多。

## 5. 建议的确认口径（供参考）

- **必传**：缺少会直接影响 GMP 合规/放行/追溯，例如批生产记录、检验记录、放行审核、工艺规程、质量标准、验收检验报告。
- **条件必传**：业务发生时必须传，不发生就不要求，例如采购订单、请检单、取样记录、偏差、验证方案。
- **可空缺**：单据本身已能表达业务，附件只是补充，例如发票、其他文件、工艺流程图、入库/出库单附件、领料单附件。
