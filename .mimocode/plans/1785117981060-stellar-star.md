# 物料编码后端自动生成方案

## 背景

当前物料（Material）的 `material_code` 字段完全由前端传入，后端不做任何自动生成处理。需要改为后端在创建物料时自动生成编码。

## 编码规则

- **格式**: 分类前缀 + 4位流水号
- **前缀映射**（仅支持以下三种分类）:
  - 原料 → `Y`
  - 辅料 → `F`
  - 包材 → `B`
- 不在以上分类范围的，拒绝创建并提示错误
- **示例**: `Y0001`、`F0001`、`B0001`
- **流水号**: 按分类独立递增，4位补零

## 修改方案

### 1. MaterialMapper 添加查询方法

**文件**: `src/main/java/com/tonghui/erp/Data/mapper/MaterialMapper.java`

添加按分类查询最大编码的方法：

```java
@Select("SELECT MAX(material_code) FROM material WHERE material_code LIKE CONCAT(#{prefix}, '%') AND is_deleted = 0")
String getMaxCodeByPrefix(@Param("prefix") String prefix);
```

### 2. MaterialService 接口添加方法

**文件**: `src/main/java/com/tonghui/erp/Service/MaterialService.java`

```java
String generateMaterialCode(String categoryName);
```

### 3. MaterialServiceImpl 实现生成逻辑

**文件**: `src/main/java/com/tonghui/erp/Service/impl/MaterialServiceImpl.java`

添加：
- 分类名称到前缀的映射方法
- `generateMaterialCode()` 方法：查询最大编码 → 解析序号 → 生成下一个编码
- 在 `addMaterial()` 中调用自动生成，忽略前端传入的编码
- 校验分类名称必须为"原料"/"辅料"/"包材"之一，否则抛出异常

### 4. MaterialController 修改

**文件**: `src/main/java/com/tonghui/erp/Controller/MaterialController.java`

`doCreate` 方法中不再依赖前端传入的 `materialCode`，由 Service 层自动生成。
