# 房间信息表新增字段

## 需求描述

在房间信息表（room_info）中增加两个字段：
1. **功能间分类**：单选，选项为 车间、仓储、检验、工程
2. **涉及工序**：多选，选择'工序信息'中'工序名'

## 设计方案

### 字段设计

| 字段名 | 数据库列名 | 类型 | 说明 |
|--------|-----------|------|------|
| `functionType` | `function_type` | VARCHAR(50) | 功能间分类（单选） |
| `relatedProcesses` | `related_processes` | VARCHAR(500) | 涉及工序（多选，逗号分隔存储） |

### 多选字段存储方式

参考项目中已有的 `productionType` 字段模式，使用**逗号分隔的字符串**存储多选值。

例如：涉及工序为"提取"和"配制"时，存储为 `"提取,配制"`

### 修改文件清单

| 文件 | 修改内容 |
|------|----------|
| RoomInfo.java | 新增 `functionType` 和 `relatedProcesses` 字段 |
| SQL 脚本 | 新增两个字段的 ALTER TABLE 语句 |

### SQL 脚本

```sql
-- 新增功能间分类字段
ALTER TABLE `room_info`
ADD COLUMN `function_type` VARCHAR(50) DEFAULT '' COMMENT '功能间分类（车间/仓储/检验/工程）' AFTER `room_status`;

-- 新增涉及工序字段
ALTER TABLE `room_info`
ADD COLUMN `related_processes` VARCHAR(500) DEFAULT '' COMMENT '涉及工序（多个以逗号分隔）' AFTER `function_type`;
```

## 验证

1. `./mvnw compile` 编译通过
2. 测试创建房间时设置功能间分类和涉及工序
3. 测试查询房间时返回这两个字段
