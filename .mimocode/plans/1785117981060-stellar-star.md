# 剂型唯一性校验 + 设备状态字段修改

## 需求描述

1. **剂型（DosageForm）**：剂型大类相同的剂型名称不能重复
2. **设备（Equipment）**：`equipmentStatus` 字段改成 正常/停用/报废

## 修改方案

### 1. 剂型唯一性校验

**修改文件**：`DosageFormController.java`

在 `doCreate` 和 `doUpdate` 方法中添加校验逻辑：
- 查询同一 `dosageCategory` 下是否存在相同 `dosageName` 的记录
- 创建时如果存在则抛出异常
- 更新时如果存在且不是当前记录则抛出异常

### 2. 设备状态字段修改

**修改内容**：
- 将 `equipmentStatus` 从 `Integer`（0/1）改为 `String`（正常/停用/报废）
- 更新所有使用该字段的地方

**修改文件**：
| 文件 | 修改内容 |
|------|----------|
| Equipment.java | `equipmentStatus` 类型从 Integer 改为 String |
| EquipmentServiceImpl.java | `listActive()` 查询条件改为 `equipmentStatus = "正常"` |
| SQL 脚本 | 修改字段类型和数据 |

### SQL 脚本

```sql
-- 修改设备状态字段类型
ALTER TABLE `equipment`
MODIFY COLUMN `equipment_status` VARCHAR(20) DEFAULT '正常' COMMENT '设备状态（正常/停用/报废）';

-- 更新现有数据
UPDATE `equipment` SET `equipment_status` = '正常' WHERE `equipment_status` = '1';
UPDATE `equipment` SET `equipment_status` = '停用' WHERE `equipment_status` = '0';
```

## 验证

1. `./mvnw compile` 编译通过
2. 测试剂型创建时同大类下名称不能重复
3. 测试设备状态字段使用新值
