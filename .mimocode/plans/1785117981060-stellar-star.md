# 制剂触发器逻辑移到后端

## 需求描述

将 `preparation` 表的 `after_preparation_insert` 触发器逻辑移到后端代码中。

## 触发器逻辑

```sql
-- 当插入新制剂记录时，如果状态为1，则为每个启用的生产单位创建库存记录
IF NEW.status = 1 THEN
    INSERT INTO stock (prod_unit_id, item_type, item_id, item_code, item_name,
                       category_name, unit_name, quantity, batch_number, production_date,
                       stock_status, created_by)
    SELECT pu.prod_unit_id, 'preparation', NEW.preparation_id, NEW.preparation_code,
           NEW.preparation_name, '制剂', COALESCE(NEW.unit_name, '个'), 0.000,
           CONCAT('AUTO_', DATE_FORMAT(NOW(), '%Y%m%d'), '_', NEW.preparation_id),
           CURDATE(), 'normal', NEW.created_by
    FROM production_unit pu WHERE pu.prod_unit_status = 1;
END IF
```

## 修改方案

### 修改文件

1. **PreparationServiceImpl.java** - 在 `addPreparation` 方法中添加创建库存记录的逻辑
2. **StockMapper.java** - 已有 `softDeleteByProdUnitId` 方法，无需修改

### 实现逻辑

在 `PreparationServiceImpl.addPreparation()` 方法中：
1. 保存制剂记录
2. 如果 `status == 1`，则为每个启用的生产单位创建库存记录

### SQL

```sql
-- 删除触发器
DROP TRIGGER IF EXISTS after_preparation_insert;
```

## 验证

1. `./mvnw compile` 编译通过
2. 创建状态为1的制剂，验证库存记录自动创建
3. 创建状态为0的制剂，验证库存记录不创建
