# 修复方案：软删除唯一键冲突 + 功能优化

## 问题列表

1. **ProcessType 创建失败** - `process_name` 有唯一约束 `uk_process_name`，软删除记录占据唯一键
2. **ProductionUnit 创建失败** - `prod_unit_code` 有唯一约束 `uk_prod_unit_code`，软删除记录占据唯一键
3. **Material search 排序** - 需要改成按创建时间排序
4. **发票接口** - 需要改成批量保存

## 修复方案

### 1. ProcessType - 添加 processName 清理逻辑

**问题**：代码只清理了 `process_code`，但数据库还有 `process_name` 的唯一约束

**修改文件**：
- `Data/mapper/ProcessTypeMapper.java` - 添加 `physicalDeleteByProcessName` 方法
- `Service/impl/ProcessTypeServiceImpl.java` - 添加 `cleanSoftDeletedByProcessName` 方法
- `Service/ProcessTypeService.java` - 添加方法声明
- `Controller/ProcessTypeController.java` - 在 doCreate 中调用清理

### 2. ProductionUnit - 添加 prodUnitCode 清理逻辑

**问题**：没有 `cleanSoftDeletedByProdUnitCode` 方法

**修改文件**：
- `Data/mapper/ProductionUnitMapper.java` - 添加 `physicalDeleteByProdUnitCode` 方法
- `Service/impl/ProductionUnitServiceImpl.java` - 添加 `cleanSoftDeletedByProdUnitCode` 方法，在 addProductionUnit 中调用
- `Service/ProductionUnitService.java` - 添加方法声明

### 3. Material search - 修改排序逻辑

**问题**：当前按 `material_code` 倒序，需要改成按创建时间排序

**修改文件**：
- `Service/impl/MaterialServiceImpl.java` - 修改 queryMaterials 方法的排序

### 4. 发票接口 - 改成批量保存

**问题**：当前只支持单条添加

**修改文件**：
- `Service/impl/ProductionUnitServiceImpl.java` - 添加 `addProdUnitInvoices` 批量方法
- `Service/ProductionUnitService.java` - 添加方法声明
- `Controller/ProductionUnitController.java` - 修改接口支持批量

## 验证

1. `./mvnw compile` 编译通过
2. 测试 ProcessType 创建（名称重复时）
3. 测试 ProductionUnit 创建（编码重复时）
4. 测试 Material search 按创建时间排序
5. 测试发票批量保存接口
