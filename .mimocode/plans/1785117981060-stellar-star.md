# 物料信息模块修改方案

## 修改需求

1. **新增'物料属性'字段**，根据'分类'选择：
   - 原料：中药材、中药饮片、原料药
   - 辅料：防腐剂、崩解剂、矫味剂、粘合剂、赋形剂
   - 包材：内包材、外包材

2. **新增'存储要求'字段**（文本框）

3. **'单位'改名为'计量单位'**

4. **'物料编码'改为手动填写**（之前是自动生成）

## 修改方案

### 1. 数据库修改

```sql
-- 添加物料属性字段
ALTER TABLE `material`
ADD COLUMN `material_attribute` VARCHAR(50) DEFAULT '' COMMENT '物料属性';

-- 添加存储要求字段
ALTER TABLE `material`
ADD COLUMN `storage_requirement` VARCHAR(500) DEFAULT '' COMMENT '存储要求';

-- 将 unit_name 字段注释修改为'计量单位'
ALTER TABLE `material`
MODIFY COLUMN `unit_name` VARCHAR(50) DEFAULT '' COMMENT '计量单位';
```

### 2. Material 实体类修改

**文件**: `src/main/java/com/tonghui/erp/Data/Entity/Material.java`

添加两个字段：
- `materialAttribute` - 物料属性
- `storageRequirement` - 存储要求

### 3. MaterialServiceImpl 修改

**文件**: `src/main/java/com/tonghui/erp/Service/impl/MaterialServiceImpl.java`

- `addMaterial()` 方法：移除自动生成编码逻辑，改为使用前端传入的编码
- 移除 `generateMaterialCode()` 方法（或保留但不调用）

### 4. MaterialController 修改

**文件**: `src/main/java/com/tonghui/erp/Controller/MaterialController.java`

- `doCreate()` 方法：移除编码自动生成逻辑

### 5. MaterialMapper 修改

**文件**: `src/main/java/com/tonghui/erp/Data/mapper/MaterialMapper.java`

- 保留 `getMaxCodeByPrefix()` 方法（可选，如果需要查询最大编码）

|------|-------------|

| 包材 | 内包材、外包材 |
