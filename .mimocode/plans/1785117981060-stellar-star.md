# 剂型字段扩展方案

## 需求描述

1. 剂型表（dosage_form）的 `dosage_name` 字段改成**剂型大类**
2. 剂型表需要添加一个**剂型名称**字段
3. 物料信息表（material）需要记录这两个字段

## 方案分析

### 方案对比

| 方案 | 优点 | 缺点 |
|------|------|------|
| **方案1：直接添加字段** | 与项目设计理念一致（不用外键），简单直接 | 数据冗余，更新剂型名称需同步更新物料 |
| **方案2：关联表** | 数据一致性好，无冗余 | 与项目设计理念不一致，增加查询复杂度 |

### 推荐方案：方案1（直接添加字段）

**理由**：
- 项目设计理念是"不用外键"，分类和单位均以文本形式存储
- Material 表已有 `category_name`、`material_attribute`、`unit_name` 等文本字段的模式
- 物料的剂型信息一旦确定，很少变更
- 查询简单，无需关联查询

## 修改方案

### 1. 数据库修改

```sql
-- 剂型表：dosage_name 改名为 dosage_category，新增 dosage_name 字段
ALTER TABLE `dosage_form`
CHANGE COLUMN `dosage_name` `dosage_category` VARCHAR(50) NOT NULL COMMENT '剂型大类';

ALTER TABLE `dosage_form`
ADD COLUMN `dosage_name` VARCHAR(50) DEFAULT '' COMMENT '剂型名称' AFTER `dosage_category`;

-- 物料表：新增剂型大类和剂型名称字段
ALTER TABLE `material`
ADD COLUMN `dosage_category` VARCHAR(50) DEFAULT '' COMMENT '剂型大类' AFTER `storage_requirement`;

ALTER TABLE `material`
ADD COLUMN `dosage_name` VARCHAR(50) DEFAULT '' COMMENT '剂型名称' AFTER `dosage_category`;
```

### 2. 实体类修改

**DosageForm.java**：
- `dosageName` 改名为 `dosageCategory`
- 新增 `dosageName` 字段

**Material.java**：
- 新增 `dosageCategory` 字段
- 新增 `dosageName` 字段

### 3. 相关文件修改

| 文件 | 修改内容 |
|------|----------|
| DosageForm.java | 字段改名 + 新增字段 |
| Material.java | 新增两个字段 |
| DosageFormMapper.java | 更新唯一约束清理方法 |
| DosageFormServiceImpl.java | 更新清理逻辑 |
| DosageFormController.java | 更新查询条件 |
| MaterialServiceImpl.java | 更新查询条件 |
