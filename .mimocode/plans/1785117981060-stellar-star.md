# 统一软删除清理方案

## 问题描述

软删除存在两类问题：
1. **唯一约束冲突** - 新增时唯一字段（编码、姓名等）与已软删除记录冲突
2. **外键约束冲突** - 物理删除父表时被子表外键阻塞

## 统一解决方案

### 设计思路

创建统一的 `SoftDeleteCleanHelper` 工具类，封装清理逻辑：
- 按唯一字段清理已软删除记录（解决唯一约束）
- 级联清理子表记录（解决外键约束）

### 新增文件

**`Common/utils/SoftDeleteCleanHelper.java`** - 统一清理工具类

```java
@Component
public class SoftDeleteCleanHelper {
    /**
     * 清理指定表中已软删除的记录（按唯一字段）
     * @param mapper Mapper实例
     * @param tableName 表名
     * @param uniqueField 唯一字段名
     * @param uniqueValue 唯一字段值
     */
    public void cleanByUniqueField(BaseMapper<?> mapper, String tableName, 
                                    String uniqueField, Object uniqueValue) {
        // 使用 QueryWrapper 物理删除
        QueryWrapper<?> wrapper = new QueryWrapper<>();
        wrapper.eq(uniqueField, uniqueValue);
        wrapper.eq("is_deleted", 1);
        mapper.delete(wrapper);
    }
}
```

### 修改现有代码

将所有 `physicalDelete*` 方法改为使用统一工具类，减少重复代码。

### 实施步骤

1. 创建 `SoftDeleteCleanHelper` 工具类
2. 修改各 Mapper，移除重复的 physicalDelete 方法
3. 修改各 Service 的 cleanSoftDeleted 方法，使用统一工具类
4. 对于有子表依赖的表，先清理子表再清理父表
