# Dashboard Charts 接口修改方案

## 一、当前问题

| 问题 | 当前实现 | UI 期望 |
|------|---------|---------|
| 剂型分组 | 按 `preparationName` 分组 | 按 `dosageForm`（丸剂/颗粒剂/胶囊）分组 |
| 总计折线 | 无 | 每月有"总计"折线叠加在柱状图上 |
| 产值单位 | 原始值 | 万元（÷10000） |
| 库存饼图 | `Map<String, Double>` | 需要百分比和总金额 |

## 二、修改方案

### 2.1 修改 DashboardController.getCharts()

**核心改动**：
1. 查 ProductionPlan 时关联 Preparation 表获取 `dosageForm`
2. 按 `dosageForm` 分组统计交付数量和产值
3. 添加每月"总计"计算
4. 库存饼图添加百分比和总金额

**SQL 关联**：ProductionPlan 的 `preparation_code` → Preparation 的 `preparation_code` → 获取 `dosage_form`

### 2.2 修改 ChartDataDto

```java
@Data
public class ChartDataDto {
    /** 交付数量按剂型（月度） */
    private List<Map<String, Object>> deliveryByDosageForm;
    /** 预估产值（月度） */
    private List<Map<String, Object>> revenueByMonth;
    /** 库存资金占用 */
    private Map<String, Double> inventoryFundOccupation;
}
```

DTO 结构不变，保持 `Map<String, Object>` 灵活性，前端按 key 取值。

### 2.3 数据格式示例

**deliveryByDosageForm / revenueByMonth**：
```json
[
  { "月份": "1月", "丸剂": 5, "颗粒剂": 3, "胶囊": 2, "总计": 10 },
  { "月份": "2月", "丸剂": 4, "颗粒剂": 2, "胶囊": 1, "总计": 7 }
]
```

**inventoryFundOccupation**：
```json
{ "原料": 85.0, "辅料": 52.0, "包材": 65.0, "耗材": 30.0 }
```
