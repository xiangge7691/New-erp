# Dashboard 时间筛选支持方案

## 现状

| 接口 | 支持时间筛选 |
|------|-------------|
| `/metrics` | ✓ |
| `/charts` | ✓ |
| `/order-tracking` | ✓ |
| `/todos` | ✗ 需添加 |
| `/summary` | ✗ 需添加 |

## 修改方案

### 1. `/todos` 接口添加时间筛选

参数：`startMonth`, `endMonth`

影响的查询：
- 设备维保：`next_maintenance_date` 在时间范围内
- 库存预警：`expiry_date` 在时间范围内
- 待入库/待确认：`created_time` 在时间范围内
- 人员管理（健康证）：`health_cert_expire` 在时间范围内
- 人员管理（证书）：`expiry_date` 在时间范围内
- 环境管理：`next_disinfection_date` 在时间范围内

### 2. `/summary` 接口添加时间筛选

参数：`startMonth`, `endMonth`

影响的查询：
- 生产统计：`created_time` 在时间范围内
- 库存统计：不受时间影响（实时数据）
- 审批统计：`created_time` 在时间范围内

## 文件清单

| 操作 | 文件路径 |
|------|---------|
| 修改 | `src/.../Controller/DashboardController.java` — getTodos 和 getSummary 方法 |

## 验证

1. `./mvnw compile` 编译通过
2. 调用 `GET /api/dashboard/todos?startMonth=2026-07&endMonth=2026-07` 验证筛选
