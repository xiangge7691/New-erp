# ERP项目代码注释补充计划

## 一、注释规范总结（依据AGENTS.md）

### 通用规则
- 所有代码文件必须添加**中文注释**
- 使用 **Javadoc 风格** (`/** */`) 注释类、接口、方法和字段
- 必须使用 `// #region` / `// #endregion` 进行逻辑分块，分块格式：
  ```java
  // #region 分块名称
  // ===================================
  // 分块名称
  // ===================================
  // 代码内容
  // #endregion
  ```
- 注释内容必须准确反映代码的实际功能，不添加无意义占位符

### 各层特殊规则
| 层级 | 类注释 | 方法注释 | 字段注释 | 特殊要求 |
|------|--------|----------|----------|----------|
| Controller | 类功能描述 | **必须包含接口传参示例**、@param、@return | - | 每个公开接口方法都需Javadoc |
| Service接口 | 类功能描述 | @param、@return | - | - |
| ServiceImpl | 类功能描述 | 方法Javadoc + 复杂逻辑行内注释 | - | - |
| Entity | 类功能+@TableName | - | **每个字段必须有Javadoc**，说明业务含义 | - |
| Dto | 类功能描述 | - | **每个字段必须有Javadoc** | - |
| Config | 类功能描述 | 方法Javadoc | @Value字段需注释 | - |
| Mapper | 类功能描述 | 自定义方法需注释 | - | 简单空接口可简略 |
| 工具类 | 类功能描述 | 方法Javadoc | - | - |

### Controller传参示例格式
```java
/**
 * 接口功能描述
 *
 * 示例请求：
 * GET /api/xxx/search?pageIndex=1&pageSize=20&param1=value1&param2=value2
 *
 * @param param1 参数1说明
 * @param param2 参数2说明
 * @return 返回值说明
 */
```

// 基本信息字段
// ===================================
/**
 * 字段中文描述（含业务含义，如：账户状态：0禁用/1启用）

@TableField(value = "column_name")

// #endregion

// #region 状态与审计字段
// ===================================
// 状态与审计字段
// ===================================
