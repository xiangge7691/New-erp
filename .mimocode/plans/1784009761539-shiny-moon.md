# 培训管理与供应商审核模块完整实施计划

## 一、需求概述

### 1.1 培训管理模块
管理制剂室各类培训活动，包括培训计划制定、执行记录、附件管理及再培训提醒。

### 1.2 供应商审核模块
记录和跟踪供应商的定期审核情况，包括审核计划、审核执行记录、审核结果及资质文件管理。

---

## 二、现有系统分析

### 2.1 已支持功能
- ✅ 文件管理模块（附件上传）
- ✅ 首页待办提醒机制
- ✅ 软删除、乐观锁等基础架构
- ✅ 供应商基本信息管理（PurchaseSuppliers）
- ✅ 统一响应格式（ApiResponse）
- ✅ 分页查询支持

### 2.2 缺失功能
- ❌ 培训管理模块（完全缺失）
- ❌ 供应商审核记录管理（缺失）
- ❌ 培训编号自动生成逻辑
- ❌ 培训周期提醒功能
- ❌ 审核周期提醒功能

```java
// 1. 培训编号生成（TRAIN-年-序号）
public String generateTrainingNo() {
    String year = String.valueOf(LocalDate.now().getYear());
    String prefix = "TRAIN-" + year + "-";
    Integer maxSeq = trainingMapper.getMaxSeqByYear(year);
    int nextSeq = (maxSeq == null) ? 1 : maxSeq + 1;
    return prefix + String.format("%03d", nextSeq);
}

// 2. 培训周期计算
public Date calculateNextTrainingDate(Date trainingDate, Integer cycleMonths) {
    Calendar cal = Calendar.getInstance();
    cal.setTime(trainingDate);
    cal.add(Calendar.MONTH, cycleMonths);
    return cal.getTime();
}

// 3. 到期提醒查询
public List<TrainingRecord> getExpiringTrainings(int days) {
    Date today = new Date();
    Date warningDate = DateUtils.addDays(today, days);
    return trainingMapper.selectExpiringTrainings(today, warningDate);
}
```
