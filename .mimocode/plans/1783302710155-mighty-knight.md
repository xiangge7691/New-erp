# 机构信息模块实现计划

## 需求概述

根据《14-机构信息.md》需求文档，实现医疗机构制剂室的机构资质信息管理模块。

**用户确认的关键决策：**
- 单机构模式（系统只维护一家机构信息，无需列表分页）
- 许可事项/登记事项变更记录暂不实现（待后续讨论）
- 许可证到期状态在查询时实时计算，无需定时任务
- 不存储文件ID，文件完全通过 `businessId + businessType` 查询

**本次实现范围：**
1. 机构许可证基础信息（单条记录，展示+编辑）
2. 机构证书子表管理（GMP证书、执业许可证、消防验收等，支持一人多证）
3. 许可证扫描件上传（通过 businessId+businessType 查询）
4. 证书到期预警（查询时实时计算）
5. 更新 FileStorageConfig 新增 ORGANIZATION 父类型

## 数据库设计

### 表1：`organization`（机构主表，仅一条记录）

```sql
CREATE TABLE organization (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    license_no VARCHAR(50) NOT NULL COMMENT '许可证证号（如：湘20260001）',
    org_name VARCHAR(200) NOT NULL COMMENT '医疗机构名称',
    org_category VARCHAR(20) NOT NULL COMMENT '医疗机构类别（医院/卫生院/诊所/其他）',
    unified_social_credit_code VARCHAR(18) NOT NULL COMMENT '统一社会信用代码',
    practice_license_no VARCHAR(50) NOT NULL COMMENT '医疗机构执业许可证号',
    legal_representative VARCHAR(50) NOT NULL COMMENT '法定代表人',
    enterprise_leader VARCHAR(50) NOT NULL COMMENT '企业负责人',
    prep_room_leader VARCHAR(50) NOT NULL COMMENT '制剂室负责人',
    preparation_address VARCHAR(200) NOT NULL COMMENT '配制地址',
    preparation_scope VARCHAR(500) NOT NULL COMMENT '配制范围',
    issuing_authority VARCHAR(100) NOT NULL COMMENT '发证机关',
    issue_date DATE NOT NULL COMMENT '发证日期',
    expiry_date DATE NOT NULL COMMENT '有效期至（自动计算：发证日期+5年）',
    license_status VARCHAR(20) NOT NULL DEFAULT '有效' COMMENT '许可证状态（有效/即将到期/已过期/注销/吊销）',
    remark VARCHAR(500) COMMENT '备注',
    status INT NOT NULL DEFAULT 1 COMMENT '状态（1启用/0停用）',
    is_deleted INT NOT NULL DEFAULT 0 COMMENT '是否已删除',
    version INT NOT NULL DEFAULT 0 COMMENT '乐观锁版本号',
    created_by BIGINT COMMENT '创建人',
    updated_by BIGINT COMMENT '更新人',
    created_time DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间'
) COMMENT='机构信息表';
```

> 注意：不存储 license_scan_file_id，许可证扫描件通过 `businessId=机构ID, businessType="ORGANIZATION_LICENSE"` 从 file_info 表查询。

### 表2：`organization_certificate`（机构证书子表）

```sql
CREATE TABLE organization_certificate (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    organization_id BIGINT NOT NULL COMMENT '关联机构ID',
    certificate_name VARCHAR(100) NOT NULL COMMENT '证书名称',
    certificate_no VARCHAR(50) COMMENT '证书编号',
    certificate_type VARCHAR(20) NOT NULL COMMENT '证书类型（机构资质/设备认证/消防许可/环保验收/其他）',
    issuing_authority VARCHAR(100) COMMENT '发证机构',
    issue_date DATE COMMENT '发证日期',
    expiry_date DATE NOT NULL COMMENT '有效期至',
    remark VARCHAR(200) COMMENT '备注',
    is_deleted INT NOT NULL DEFAULT 0 COMMENT '是否已删除',
    version INT NOT NULL DEFAULT 0 COMMENT '乐观锁版本号',
    created_by BIGINT COMMENT '创建人',
    updated_by BIGINT COMMENT '更新人',
    created_time DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    INDEX idx_organization_id (organization_id)
) COMMENT='机构证书表';
```

> 注意：不存储 certificate_file_id，证书文件通过 `businessId=证书ID, businessType="ORGANIZATION_CERTIFICATE"` 从 file_info 表查询。

## 关键实现逻辑

### 1. 有效期自动计算
```java
// OrganizationService.update 中
LocalDate expiryDate = organization.getIssueDate().plusYears(5);
organization.setExpiryDate(expiryDate);
```

### 2. 许可证状态实时计算
```java
// OrganizationService.getWithDetails 中
LocalDate today = LocalDate.now();
long daysBetween = ChronoUnit.DAYS.between(today, org.getExpiryDate());
if (daysBetween < 0) {
    org.setLicenseStatus("已过期");
} else if (daysBetween <= 30) {
    org.setLicenseStatus("即将到期");
} else {
    org.setLicenseStatus("有效");
}
```

### 3. 文件查询（不存文件ID）
```java
// 上传时
fileInfoService.uploadFileWithBusinessPath(file, "ORGANIZATION_LICENSE", orgId, orgName, "许可证扫描件");

// 查询时
List<FileInfo> files = fileInfoService.getFilesByBusiness(orgId, "ORGANIZATION_LICENSE", null);
```

### 4. 证书到期预警查询
```java
LocalDate today = LocalDate.now();
LocalDate deadline = today.plusDays(days);
QueryWrapper<OrganizationCertificate> wrapper = new QueryWrapper<>();
wrapper.eq("is_deleted", 0)
       .eq("organization_id", currentOrgId)
       .isNotNull("expiry_date")
       .le("expiry_date", deadline)
       .ge("expiry_date", today);
```

### Service 实现逻辑
```java
// OrganizationServiceImpl.createOrganization
public Organization createOrganization(Organization organization) {
    // 1. 检查是否已存在机构（单机构模式）
    Organization existing = getCurrentOrganization();
    if (existing != null) {
        throw new RuntimeException("已存在机构信息，请使用更新接口");
    }
    // 2. 自动计算有效期至 = 发证日期 + 5年
    organization.setExpiryDate(organization.getIssueDate().plusYears(5));
    // 3. 设置默认状态
    organization.setLicenseStatus("有效");
    organization.setIsDeleted(0);
    organization.setVersion(0);
    // 4. 保存
    save(organization);
    return organization;
}
```
