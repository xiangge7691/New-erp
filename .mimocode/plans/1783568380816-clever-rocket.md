# 修复 equipmentMaintenance 接口 equipmentName/fixedAssetCode 为空的问题

## 问题分析
- `equipmentName` 和 `fixedAssetCode` 都是 `@TableField(exist = false)`，不在数据库表中
- 查询后未根据 `equipmentId` 关联查询 `Equipment` 表填充这两个字段

## 修改内容

### 1. `EquipmentMaintenance.java` - 新增字段
在 `@TableField(exist = false)` 区域（第112-117行之间）新增：
```java
/**
 * 设备编码（关联equipment表）
 */
@TableField(exist = false)
private String fixedAssetCode;
```

### 2. `EquipmentMaintenanceController.java` - 添加填充逻辑

**添加私有辅助方法** `fillEquipmentInfo(List<EquipmentMaintenance>)`：
- 提取所有不重复的 `equipmentId`
- 批量查询 `Equipment` 表（`equipmentService.listByIds()`）
- 用 Map<Integer, Equipment> 匹配并填充 `equipmentName` 和 `fixedAssetCode`
- 注意：`EquipmentMaintenance.equipmentId` 是 Long，`Equipment.equipmentId` 是 Integer

**在4个查询接口的返回前调用填充方法**：
- `getAll`（第133行后）：`fillEquipmentInfo(pageResult.getRecords())`
- `getById`（第154行后）：单条记录放入 List 调用，或直接单独填充
- `reminder`（第258行后）：`fillEquipmentInfo(list)`
- `getByEquipmentId`（第292行后）：`fillEquipmentInfo(list)`

## 验证
- `GET /api/equipmentMaintenance?pageIndex=0&pageSize=10`
- 确认 `equipmentName` 和 `fixedAssetCode` 不再为 null
