# 回收站恢复：新增 originalPath 字段

## 问题
当前 `restore` 方法从 `relativePath` 参数推断原路径，不可靠。需要在删除时记录原路径。

## 修改内容

### 1. DDL
```sql
ALTER TABLE file_info ADD COLUMN original_path VARCHAR(500) NULL COMMENT '原始路径（回收站恢复用）' AFTER deleted_by;
```

### 2. `FileInfo.java` — 新增字段
```java
@TableField(value = "original_path")
private String originalPath;
```

### 3. `FileManagerServiceImpl.java`
- **delete 方法**：删除前保存 `originalPath`（文件相对于 basePath 的路径）
- **restore 方法**：从 `originalPath` 读取原路径，将文件移回原位，清除 `originalPath`
- **permanentDelete 方法**：清除 `originalPath`（可选）
