# 维保记录新增记录人字段并关联人员表

## 1. 数据库DDL
```sql
-- 在 equipment_maintenance 表中新增 recorder_id 字段
ALTER TABLE equipment_maintenance ADD COLUMN recorder_id BIGINT NULL COMMENT '记录人ID（关联personnel_file表）' AFTER remark;
```

## 2. `EquipmentMaintenanceMapper.xml` — 更新映射
- resultMap 中新增 `<result property="recorderId" column="recorder_id" />`
- Base_Column_List 中新增 `recorder_id`

## 3. `EquipmentMaintenance.java` — 新增字段
```java
/**
 * 记录人ID（关联personnel_file表）
 */
@TableField(value = "recorder_id")
private Long recorderId;

/**
 * 记录人姓名（关联personnel_file表，由recorderId查出）
 */
@TableField(exist = false)
private String recorderName;
```

## 4. `EquipmentMaintenanceController.java` — 更新 fillEquipmentInfo
- 注入 `PersonnelFileService`
- 收集所有不重复的 `recorderId`
- 批量查询 `personnel_file` 表获取 `name`
- 填充 `recorderName` 字段

## 涉及文件
- `src/main/resources/Data/mapper/EquipmentMaintenanceMapper.xml`
- `src/main/java/com/tonghui/erp/Data/Entity/EquipmentMaintenance.java`
- `src/main/java/com/tonghui/erp/Controller/EquipmentMaintenanceController.java`

## 验证
- 执行DDL SQL
- `./mvnw compile` 编译通过
- `GET /api/equipmentMaintenance?pageIndex=0&pageSize=10` 返回中包含 `recorderId` 和 `recorderName`
