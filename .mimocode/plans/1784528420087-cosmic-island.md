# PreparationProcessTemplate batchSave 主键冲突修复

## 问题
前端调用 `POST /api/preparationProcessTemplate/batch?preparationId=359` 时报错：
```
Duplicate entry '3' for key 'preparation_process_template.PRIMARY'
```

## 原因
`batchSave` 先删除旧记录，再 `saveBatch`（INSERT），但前端传入的记录带有旧 `templateId`，INSERT 时主键冲突。

## 修复
在 `PreparationProcessTemplateServiceImpl.batchSave()` 中，保存前清空 `templateId`：
```java
template.setTemplateId(null);
```

同样需要修复 `PreparationFormulaServiceImpl.batchSave()` 和 `PreparationDocumentServiceImpl.batchSave()` 中的相同问题。

## 修改文件
1. `Service/impl/PreparationProcessTemplateServiceImpl.java` — batchSave 方法
2. `Service/impl/PreparationFormulaServiceImpl.java` — batchSave 方法
3. `Service/impl/PreparationDocumentServiceImpl.java` — batchSave 方法
