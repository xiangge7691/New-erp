# 搜索接口时间范围查询全量修复计划

## 统一规范

时间范围查询参数命名统一为 `xxxStart` 和 `xxxEnd`，Service 层使用 `ge` + `le` 实现。

---

## 需要修复的文件

### 1. VerificationRecordServiceImpl — 执行日期参数重命名
**文件**: `Service/impl/VerificationRecordServiceImpl.java`

当前：`executeDate`(ge) + `executeDateEnd`(le)
修正：`executeDateStart`(ge) + `executeDateEnd`(le)

**实体文件**: `Data/Entity/VerificationRecord.java`
- 将 `executeDateEnd` 字段重命名（已经是 `@TableField(exist = false)`，无需改数据库）

### 2. TrainingRecordServiceImpl — 培训日期缺少结束日期
**文件**: `Service/impl/TrainingRecordServiceImpl.java`

当前：`trainingDate`(ge) 只有开始
修正：添加 `trainingDateEnd`(le)

**实体文件**: `Data/Entity/TrainingRecord.java`
- 添加 `trainingDateEnd` 字段（`@TableField(exist = false)`）

### 3. SupplierAuditServiceImpl — 审核日期缺少结束日期
**文件**: `Service/impl/SupplierAuditServiceImpl.java`

当前：`auditDate`(ge) 只有开始
修正：添加 `auditDateEnd`(le)

**实体文件**: `Data/Entity/SupplierAudit.java`
- 添加 `auditDateEnd` 字段（`@TableField(exist = false)`）

### 4. PreparationServiceImpl — 创建/更新时间范围混乱
**文件**: `Service/impl/PreparationServiceImpl.java`

当前：`createdTime`(ge) + `updatedTime`(le) — 混用了两个不同字段
修正：`createdTimeStart`(ge) + `createdTimeEnd`(le) + `updatedTimeStart`(ge) + `updatedTimeEnd`(le)

**实体文件**: `Data/Entity/Preparation.java`
- 添加 `createdTimeStart`、`createdTimeEnd`、`updatedTimeStart`、`updatedTimeEnd` 字段（`@TableField(exist = false)`）

### 5. MaterialServiceImpl — 创建/更新时间范围混乱
**文件**: `Service/impl/MaterialServiceImpl.java`（queryMaterials 方法）

当前：`createdTime`(ge) + `updatedTime`(le) — 混用了两个不同字段
修正：`createdTimeStart`(ge) + `createdTimeEnd`(le) + `updatedTimeStart`(ge) + `updatedTimeEnd`(le)

**实体文件**: `Data/Entity/Material.java`
- 添加 `createdTimeStart`、`createdTimeEnd`、`updatedTimeStart`、`updatedTimeEnd` 字段（`@TableField(exist = false)`）
