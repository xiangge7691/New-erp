# 验证记录执行人搜索修复

## 问题
`VerificationRecordServiceImpl.queryVerificationRecords()` 有 `category`、`verificationNo`、`verificationName`、`relatedObject`、`executeDate` 的搜索条件，但缺少 `executor`（执行人）的模糊搜索。

## 修复
在 `queryVerificationRecords` 方法中添加：
```java
if (StringUtils.hasText(verificationRecord.getExecutor())) {
    wrapper.like("executor", verificationRecord.getExecutor());
}
```
