# 制剂模块批量保存子表改造计划

## 当前问题

制剂主表下挂3个子表（处方、工序模版、文档），当前前端需要多次独立请求才能保存完整制剂：
1. `POST /api/preparation` — 仅保存主表
2. `POST /api/preparation/formula` × N — 逐条保存处方
3. `POST /api/preparationProcessTemplate/batch` — 批量保存工序模版
4. `POST /api/preparationDocument` × M — 逐条保存文档

**核心问题**：主表和子表不在同一事务中；处方和文档没有批量保存；删除主表不级联删除子表。

```java
@Transactional
public void batchSave(Long preparationId, List<PreparationFormula> formulas) {
    QueryWrapper<PreparationFormula> wrapper = new QueryWrapper<>();
    wrapper.eq("preparation_id", preparationId);
    remove(wrapper);
    if (formulas != null && !formulas.isEmpty()) {
        formulas.forEach(f -> f.setPreparationId(preparationId));
        saveBatch(formulas);
    }
}
```

### 6. PreparationServiceImpl — 实现 saveWithDetails、deleteWithDetails、getWithDetails
**文件**: `Service/impl/PreparationServiceImpl.java`

核心逻辑：
```java
@Transactional
public void saveWithDetails(PreparationWithDetailsDto dto) {
    // 1. 保存/更新主表
    if (dto.getPreparationId() == null) {
        addPreparation(dto);  // 新增
    } else {
        updatePreparation(dto); // 更新
    }
    Long prepId = dto.getPreparationId();
    
    // 2. 批量保存处方（先删后插）
    formulaService.batchSave(prepId, dto.getFormulas());
    
    // 3. 批量保存工序模版（先删后插）
    templateService.batchSave(prepId, dto.getProcessTemplates());
    
    // 4. 批量保存文档（先删后插）
    documentService.batchSave(prepId, dto.getDocuments());
}

@Transactional
public void deleteWithDetails(Long preparationId) {
    // 先删子表，再删主表
    QueryWrapper<PreparationFormula> fw = new QueryWrapper<>();
    fw.eq("preparation_id", preparationId);
    preparationFormulaMapper.delete(fw);
    
    QueryWrapper<PreparationProcessTemplate> tw = new QueryWrapper<>();
    tw.eq("preparation_id", preparationId);
    preparationProcessTemplateMapper.delete(tw);
    
    QueryWrapper<PreparationDocument> dw = new QueryWrapper<>();
    dw.eq("preparation_id", preparationId);
    preparationDocumentMapper.delete(dw);
    
    this.removeById(preparationId);
}

public PreparationWithDetailsDto getWithDetails(Long preparationId) {
    Preparation prep = this.getById(preparationId);
    if (prep == null) return null;
    PreparationWithDetailsDto dto = new PreparationWithDetailsDto();
    BeanUtils.copyProperties(prep, dto);
    dto.setFormulas(formulaService.list(new QueryWrapper<PreparationFormula>().eq("preparation_id", preparationId)));
    dto.setProcessTemplates(templateService.findByPreparationId(preparationId));
    dto.setDocuments(documentService.findByPreparationId(preparationId));
    return dto;
}
```

### 7. PreparationController — 新增接口
**文件**: `Controller/PreparationController.java`

新增3个接口：

**`POST /api/preparation/save-with-details`** — 一键保存主表+所有子表
```java
@PostMapping("/save-with-details")
public ApiResponse<Void> saveWithDetails(@RequestBody PreparationWithDetailsDto dto) {
    preparationService.saveWithDetails(dto);
    return success(null, "保存成功");
}
```

**`GET /api/preparation/{id}/details`** — 获取制剂详情（含所有子表）
```java
@GetMapping("/{id}/details")
public ApiResponse<PreparationWithDetailsDto> getWithDetails(@PathVariable Long id) {
    PreparationWithDetailsDto dto = preparationService.getWithDetails(id);
    if (dto == null) return error("制剂不存在");
    return success(dto);
}
```

**修改 `doDelete`** — 级联删除子表
```java
@Override
protected boolean doDelete(Long id) {
    preparationService.deleteWithDetails(id);
    return true;
}
```
