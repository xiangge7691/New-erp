# 培训记录到期预警优化计划

## 需求分析

1. **添加"已处理/不再提醒"字段** — 培训记录表需要新增 `reminder_status` 字段，支持标记预警已处理或不再提醒
2. **包含已过期记录** — 当前到期预警只查 `next_training_date BETWEEN today AND today+N`，已过期的记录不会显示

## 当前问题

### 培训记录到期预警SQL（`TrainingRecordMapper.java:36-40`）
```sql
SELECT * FROM training_record 
WHERE next_training_date BETWEEN #{today} AND #{warningDate} 
AND is_deleted = 0 
ORDER BY next_training_date ASC
```
- 只查即将到期的，已过期的不显示
- 没有"已处理/不再提醒"的过滤逻辑

---

## 修改清单

### 1. 数据库 — 新增字段
**文件**: `sql/create_tables.sql`

在 `training_record` 表新增字段：
```sql
`reminder_status` INT DEFAULT 0 COMMENT '预警状态（0未处理/1已处理/2不再提醒）'
```

### 2. 实体类 — 新增字段
**文件**: `src/main/java/com/tonghui/erp/Data/Entity/TrainingRecord.java`

新增 `reminderStatus` 字段。

### 3. Mapper — 修改到期查询SQL
**文件**: `src/main/java/com/tonghui/erp/Data/mapper/TrainingRecordMapper.java`

将 `selectExpiringTrainings` SQL 改为：
- `<= #{warningDate}` 包含已过期记录
- 排除 `reminder_status = 2`（不再提醒）的记录
- 按培训日期分组取最新一条

### 4. Service — 修改方法签名
**文件**: `src/main/java/com/tonghui/erp/Service/impl/TrainingRecordServiceImpl.java`

- `getExpiringTrainings()` 方法：移除 `today` 参数传递
- 新增 `updateReminderStatus(Long id, Integer status)` 方法：更新预警状态

### 5. Service接口 — 新增方法声明
**文件**: `src/main/java/com/tonghui/erp/Service/TrainingRecordService.java`

新增 `updateReminderStatus` 方法声明。

### 6. Controller — 新增预警状态更新接口
**文件**: `src/main/java/com/tonghui/erp/Controller/TrainingRecordController.java`

新增 `PUT /api/training-record/{id}/reminder-status` 接口，支持更新预警状态。
