# 为两个工序表添加「设备关键参数」字段

## 字段对比结果

| 表 | 缺失字段 |
|---|---|
| `preparation_process_template` | `equipment_params` |
| `production_process_record` | `equipment_params` |

## 修改方案

### 1. Entity 修改

#### `PreparationProcessTemplate.java` — 添加字段
```java
@TableField(value = "equipment_params")
private String equipmentParams;
```

#### `ProductionProcessRecord.java` — 添加字段
```java
@TableField(value = "equipment_params")
private String equipmentParams;
```

### 2. 数据库迁移 `db/fix_add_equipment_params.sql`

```sql
ALTER TABLE `preparation_process_template` 
  ADD COLUMN `equipment_params` VARCHAR(500) DEFAULT NULL COMMENT '设备关键参数' AFTER `equipment_desc`;

ALTER TABLE `production_process_record` 
  ADD COLUMN `equipment_params` VARCHAR(500) DEFAULT NULL COMMENT '设备关键参数' AFTER `equipment`;
```

### 3. Controller/Service 无需修改

因为 Entity 已添加字段，MyBatis-Plus 会自动处理 CRUD。

## 验证

1. `./mvnw compile` 确认编译通过
2. 在生产数据库执行迁移 SQL
3. 测试接口确认新字段可正常读写
