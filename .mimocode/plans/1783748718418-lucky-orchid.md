# 文件管理模块改造计划

## 需求概述

1. **文件夹大小回参**：`listDirectory` 和 `searchFiles` 返回的文件夹项需包含实际大小（递归计算子文件总大小）
2. **路径模糊搜索**：搜索接口支持按路径模糊匹配
3. **按大小筛选**：搜索支持 `minSize` / `maxSize` 参数
4. **按修改日期筛选**：搜索支持 `modifiedAfter` / `modifiedBefore` 日期范围参数
5. **目录列表也支持筛选**：`listDirectory` 返回的文件列表支持同样的大小/日期筛选

---

## 详细改造步骤

### 第1步：FileItemDto 文件夹 size 返回实际大小

**文件**: `Common/Dto/FileManager/FileItemDto.java`

无需修改字段。改造 `FileManagerServiceImpl` 中所有将文件夹 `size` 设为 `0L` 的地方，改为递归计算文件夹内所有文件的大小之和。

### 第2步：新建 FileSearchRequestDto

**文件**: `Common/Dto/FileManager/FileSearchRequestDto.java`（新建）

```java
@Data
public class FileSearchRequestDto {
    private String keyword;          // 文件名关键词（模糊匹配）
    private String path;             // 路径模糊匹配
    private String root;             // 根目录类型，默认 custom
    private Long minSize;            // 最小文件大小（字节）
    private Long maxSize;            // 最大文件大小（字节）
    private String modifiedAfter;    // 修改时间起始（yyyy-MM-dd HH:mm:ss）
    private String modifiedBefore;   // 修改时间截止（yyyy-MM-dd HH:mm:ss）
    private Integer pageIndex;       // 页码，默认 0
    private Integer pageSize;        // 每页大小，默认 20
}
```

#### 6.2 路径模糊匹配
在 `searchFiles` 中，除了现有的文件名匹配，增加路径匹配：
```java
walk.filter(path -> {
    boolean nameMatch = keyword == null || path.getFileName().toString().toLowerCase().contains(keyword.toLowerCase());
    boolean pathMatch = request.getPath() == null || 
        normalizePath(basePath.relativize(path).toString()).toLowerCase().contains(request.getPath().toLowerCase());
    return nameMatch && pathMatch;
})
```

#### 6.3 大小筛选
```java
.filter(path -> {
    if (Files.isRegularFile(path)) {
        long size = Files.size(path);
        if (minSize != null && size < minSize) return false;
        if (maxSize != null && size > maxSize) return false;
    }
    return true;
})
```

#### 6.4 日期筛选
```java
.filter(path -> {
    FileTime modifiedTime = Files.getLastModifiedTime(path);
    LocalDateTime ldt = LocalDateTime.ofInstant(modifiedTime.toInstant(), ZoneId.systemDefault());
    if (after != null && ldt.isBefore(after)) return false;
    if (before != null && ldt.isAfter(before)) return false;
    return true;
})
```

#### 6.5 分页实现
搜索结果收集到 List 后，通过 `Page` 或手动截取实现分页。

### 第7步：DirectoryListingDto 文件列表筛选

在 `listDirectory` 中对 `files` 列表应用相同的大小/日期筛选逻辑（筛选不影响文件夹列表）。
